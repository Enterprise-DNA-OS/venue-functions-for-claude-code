# Update a venue record

Read the record first. Supply only changed fields. Parent relationships and receipt edits are blocked. Never certify a review that has not happened.

Run `npm run venue -- update <entity> <name-or-id> <json>`. Use `--json` for structured results. Replace angle-bracket placeholders with supplied values and quote them for the current shell. Never infer missing records.
