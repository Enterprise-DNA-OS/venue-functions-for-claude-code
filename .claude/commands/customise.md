# Customise

Read CLAUDE.md and the affected command, migration and smoke test. Ask for the actual field, stage or rule when it is missing. Back up real data. Write an additive migration in supabase/migrations, never change an applied migration. Update the CLI, documents, instructions and a meaningful regression test. Run npm test against temporary data, then npm run migrate against the authorised database. Read the result back. Never record a compliance check as complete without the operator's evidence.
