# Draft a booking follow-up

Read the event, notes and money first. Run the draft and review the draft file. Nothing sends. Remove internal source records before sharing.

Run `npm run venue -- draft-follow-up <event>`. Use `--json` for structured results. Replace angle-bracket placeholders with supplied values and quote them for the current shell. Never infer missing records.
