# Read a full record

Use the operator-supplied match. For events this includes menu items, sessions, shifts, tasks, receipts and notes. Ambiguity lists candidates and exits 1.

Run `npm run venue -- record <entity> <name-or-id>`. Use `--json` for structured results. Replace angle-bracket placeholders with supplied values and quote them for the current shell. Never infer missing records.
